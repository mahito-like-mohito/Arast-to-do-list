# Arast Features

Complete feature list for Arast. This is the detailed reference. The README only highlights the most important ones.

## Planning

* Morning, Noon and Night time blocks with sticky headers
* Quick task creation from the home screen floating button
* Inline calendar in the task editor
* Circular hour and minute dials with AM and PM toggle in the center
* Start and end time shown under each task title
* Smart free slot suggestions learned from your own history
* Strict time blocking, overlapping tasks cannot be saved
* Search across all tasks
* Deep focus mode to hide the noise
* Auto rollover of unfinished tasks to the next day

## Reminders

* Two step reminder: silent vibration first, then sound just before the task starts
* Works even when the app is closed or the phone restarted
* Per task alarm toggle
* Choice of system ringtone or your own audio file
* Adjustable early warning time
* Quiet hours with selectable vibration patterns
* Exact Android alarms with boot restore, so reminders survive reboot

## Task management

* Swipe right to edit, swipe left to delete
* Three dot menu with Edit and Delete
* Hold a task for 3 seconds to see exact time remaining
* Live progress ring and progress bar on the active task card
* Notes hidden under each card, pull the bottom edge to reveal
* 5 second undo with countdown ring after delete
* Trash with 30 day retention, restore or purge manually

## Personalization

* RGB color wheel that rethemes the app live
* Custom background image drawn edge to edge behind everything
* Custom background colors applied app wide
* Light blue and brown default theme that stays readable with any accent color
* Encouraging header copy for each time of day
* Pre task vibration toggle and pattern preview

## Insights and privacy

* Weekly insights dashboard with completion and overtime stats
* Settings center for defaults, quiet hours, security, focus, gestures, display and cleanup
* Biometric app lock and secure screen
* Fully offline, all data stays on the device with SQLite
